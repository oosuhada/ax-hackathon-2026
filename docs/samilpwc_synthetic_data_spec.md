# 삼일PwC 합성 데이터 스펙 (Synthetic Data Spec)

## 1. 목적
SOP 연동 설명 엔진 및 객관적 판독 리포트 생성을 시뮬레이션하기 위한 합성(가상) 경영 데이터 및 SOP 지식베이스 명세.

## 2. 원칙
- **전면 가상화**: 모든 샘플 데이터는 `[SYNTHETIC]`으로 명시적으로 라벨링되어야 한다.
- **금칙어**: 실제 고객사명, 임원명, 실제 프로젝트명, 특정될 수 있는 구체 금액은 사용을 엄격히 금지한다.
- **검증 목적**: 데이터는 완벽한 정상 상태가 아니라 의도적으로 `이상 패턴(Anomaly)`을 내포하도록 구성하여, 에이전트의 판단력을 검증할 수 있어야 한다.

## 3. Dummy_Business_Data.json 스펙
- `business_unit_metrics`, `cost_allocations`, `revenue_trends`를 포함하는 구조.
- "Unit_A" 같은 무기명 부서 코드를 사용한다.

## 4. Dummy_SOP_Snippets.json 스펙
- 조직 내 원가 배분 규정, 성과 측정 기준, 감사 기준 등의 가상 규정 조항 포함.
- 문서 번호(e.g. SOP-FIN-042)와 규정 원문을 포함.
