# 카카오페이증권: kps-investor-risk-brief 플러그인

이 플러그인은 AI 기반 투자정보와 뉴스 요약을 투자자 보호 관점에서 점검하고, 리스크 고지 및 쉬운 설명을 보완해 주는 Codex 플러그인입니다.

## 1. 플러그인 작동 방식
사용자가 검토가 필요한 투자정보 요약 텍스트를 입력하면, Codex가 텍스트 내 과장된 표현이나 누락된 리스크 요인(원금 손실, 환율 등)을 식별합니다. 이후, 이를 수정할 안전한 문구와 투자권유가 아님을 명시하는 리포트를 반환합니다.

## 2. 사용 방법
1. Codex 환경에 본 플러그인을 로드합니다 (`src/.codex-plugin/plugin.json`).
2. 플러그인의 `kps-investor-risk-brief` 스킬을 호출하며 검토할 텍스트를 인풋으로 전달합니다.
3. 안전하게 수정된 브리핑과 리스크 분석 보고서를 확인합니다.

## 3. 검증 환경
본 플러그인은 AI가 텍스트를 검토하여 누락된 리스크(환율, 변동성 등)를 찾아내는지, 그리고 투자 조언(매수/매도)을 직접적으로 하지 않도록 하는 Guardrail이 올바르게 작동하는지 중점적으로 검증합니다.
