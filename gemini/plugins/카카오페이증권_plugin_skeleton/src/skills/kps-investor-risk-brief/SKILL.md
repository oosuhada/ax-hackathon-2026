# Purpose
초보 투자자들이 AI가 생성하거나 요약한 주식 뉴스/정보를 볼 때 원금손실, 환율, 변동성 등의 중요한 리스크 요인을 놓치거나 '투자 권유'로 오해하는 것을 방지하기 위함입니다. 
본 스킬은 제공된 정보를 투자자 보호 규제 관점에서 검토하고, 누락된 리스크 고지 문구와 수정안을 제안합니다.

# When to use this skill
- AI 기반 투자정보 요약이나 해외주식 뉴스 번역글을 배포하기 전 검토 단계
- 투자 관련 글 내에 과장된 수익성 표현이 있거나 리스크 고지(원금 손실 가능성 등)가 부족할 때
- 출처가 불분명하거나 환율, 밸류에이션 등의 맥락이 빠진 투자 분석 글을 수정할 때

# Required inputs
- `investment_summary_text`: 검토할 원본 투자 정보/뉴스 요약 텍스트
- (Optional) `source_links`: 원본 기사나 정보의 출처 링크

# Workflow
1. **위험 표현 식별**: 텍스트 내에서 특정 종목의 '매수 추천', '수익 보장' 등 투자 권유로 오인할 수 있는 과장된 표현을 찾습니다.
2. **누락된 리스크 점검**: 환율 변동, 원금 손실 가능성, 해당 산업의 변동성 등 필수 리스크 고지 내용이 있는지 확인합니다.
3. **출처 추적 및 확인**: 제공된 출처 링크를 통해 해당 정보가 검증 가능한지 확인합니다.
4. **리포트 생성**: 위 3단계를 종합하여 수정이 필요한 문구, 보완할 위험 고지 문장, 그리고 출처 추적 결과를 표와 요약 리포트 형태로 생성합니다.

# Output format
- 위험 표현 점검 결과 표 (위험 문구, 이유, 수정 제안)
- 추가해야 할 투자자 보호 문구 및 면책 조항 (투자권유 아님 고지)
- 이해하기 쉬운 한국어로 재작성된 안전한 최종 요약문

# Validation checklist
- [ ] 본문에 '매수', '매도' 등 직접적인 투자 조언이 포함되지 않았는가?
- [ ] 원금 손실 가능성과 변동성 위험이 명확히 고지되었는가?
- [ ] 출력된 최종 결과물이 투자 권유로 오해될 소지는 없는가?

# Guardrails
- **DO NOT** provide financial advice. 본 스킬과 플러그인은 투자 자문을 제공하지 않으며, 투자 의사결정을 대체할 수 없습니다. 
- **DO NOT** make up numbers. 공개자료나 제공된 텍스트에 없는 수치나 정보를 임의로 생성하지 마십시오.
- 본 도구는 오직 정보 검토 및 리스크 브리핑 보조 도구로만 사용되어야 합니다.

# Example
사용자가 테슬라 주식 상승에 대한 긍정적인 전망만 담긴 요약글을 입력하면, Codex는 "테슬라의 성장성은 주목받고 있으나 전기차 시장의 변동성과 환율 변동에 따른 원금 손실 위험을 주의해야 합니다. 본 정보는 투자 권유가 아닙니다." 와 같은 균형 잡힌 리스크 브리핑과 면책 조항을 함께 출력합니다.
