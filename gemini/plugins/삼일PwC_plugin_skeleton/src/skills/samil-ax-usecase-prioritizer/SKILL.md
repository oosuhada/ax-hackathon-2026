# Purpose
많은 기업들이 생성형 AI 도입의 필요성을 느끼지만 "어떤 업무부터" 적용해야 할지, "ROI와 리스크"를 어떻게 비교할지 막막해합니다.
본 스킬은 삼일PwC의 경영 컨설팅 노하우를 바탕으로 고객사의 주요 업무 목록을 평가하여, Quick Win을 달성할 수 있는 최적의 AX 유스케이스(Use Case)를 선별하고 초기 PoC 계획 수립을 보조합니다.

# When to use this skill
- 기업 고객의 업무 목록과 페인포인트 데이터를 바탕으로 AX 도입 전략을 수립할 때
- 부서별 다수의 업무 중 ROI가 높고 데이터 준비도가 높은 '최우선 AI 도입 과제'를 필터링할 때
- 도출된 유스케이스에 대한 PoC(개념 증명) 플랜과 리스크/거버넌스 체크리스트가 필요할 때

# Required inputs
- `business_processes`: 고객사의 부서별 주요 업무, 발생 빈도, 소요 시간, 페인포인트 목록 (CSV 또는 텍스트 구조화 데이터)
- `company_context`: 기업의 산업군 및 현재 디지털 인프라 수준

# Workflow
1. **업무 분석 및 AX 적합성 평가**: 입력된 `business_processes`를 분석하여 생성형 AI(요약, 초안 작성, 분류, 검색 등)로 해결 가능한 업무를 필터링합니다.
2. **우선순위 매트릭스 구성**: ROI(비용 절감, 효율성 증가)와 구현 용이성(데이터 준비도, 리스크 수용성)을 기준으로 2x2 매트릭스 점수를 부여합니다.
3. **Quick Win 과제 선정**: 2x2 매트릭스에서 가장 높은 점수(High ROI, Easy Implementation)를 기록한 최상위 1~3개의 과제를 선별합니다.
4. **실행 계획(PoC) 및 리포트 작성**: 선별된 최우선 과제에 대해 예상되는 정량적/정성적 효과, 3단계 PoC 로드맵, 그리고 반드시 짚어야 할 보안/거버넌스 리스크 체크리스트를 포함한 리포트를 생성합니다.

# Output format
- 모든 후보 업무에 대한 [우선순위 매트릭스 점수표]
- 최상위 과제(Quick Win)에 대한 [Executive One-pager (요약본)]
- 해당 과제의 [PoC 실행 로드맵 및 리스크 체크리스트]

# Validation checklist
- [ ] 입력된 실제 고객사 업무 목록만을 바탕으로 평가하였는가?
- [ ] ROI 산정 근거와 데이터 준비도 평가 기준이 논리적으로 설명되었는가?
- [ ] 보안이나 환각(Hallucination)에 대한 필수 리스크 통제 방안이 포함되었는가?

# Guardrails
- **DO NOT** make up generic use cases. 일반적이고 뻔한 AI 활용 사례를 임의로 지어내지 마십시오. 반드시 사용자가 입력한 업무 데이터(`business_processes`)에 기반하여 구체적인 과제를 도출해야 합니다.
- 이 플러그인은 경영 의사결정을 보조하는 도구일 뿐, 생성된 결과가 최종적인 재무적/기술적 투자 보증을 의미하지 않음을 명시해야 합니다.

# Example
사용자가 인사팀과 영업팀의 10개 업무 리스트를 입력하면, Codex는 "영업 제안서 초안 작성"을 가장 ROI가 높고 실행하기 쉬운 최우선 과제로 선정하고, 이를 4주간 검증하기 위한 PoC 계획과 '기밀 유출 방지를 위한 사내 전용 모델 구축 필요성' 등의 거버넌스 체크리스트를 출력합니다.
