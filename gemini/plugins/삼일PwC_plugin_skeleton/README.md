# 삼일PwC: samil-ax-usecase-prioritizer 플러그인

이 플러그인은 기업들이 생성형 AI(AX)를 도입할 때 겪는 "어떤 업무부터 적용해야 하는가?"라는 문제를 해결하기 위해, ROI와 구현 용이성을 바탕으로 업무별 우선순위를 매기고 최적의 Use Case를 도출하는 Codex 플러그인입니다.

## 1. 플러그인 작동 방식
사용자가 부서별 주요 업무와 페인포인트 목록을 제공하면, Codex가 이를 분석하여 2x2 우선순위 매트릭스(ROI vs 구현 용이성)를 그리고 가장 효과적인 'Quick Win' 과제를 선별합니다. 나아가 초기 PoC 계획과 리스크/거버넌스 체크리스트까지 함께 제공합니다.

## 2. 사용 방법
1. Codex 환경에 본 플러그인을 로드합니다 (`src/.codex-plugin/plugin.json`).
2. `samil-ax-usecase-prioritizer` 스킬을 호출하고 `business_processes` 데이터를 입력합니다.
3. 생성된 우선순위 매트릭스와 Executive One-pager(최우선 과제 실행 계획)를 컨설팅 자료로 활용합니다.

## 3. 검증 환경
제안된 결과가 단순히 뻔한 AI 활용론에 그치지 않고, 고객사가 입력한 실제 업무 기반으로 구체적이고 타당하게 도출되었는지, ROI 기준이 논리적인지를 중점적으로 검증합니다.
