# 삼일PwC — 5문항 답변 초안

## 1. 무엇을, 누가, 어떤 상황에서 쓰나요?

`samil-ax-usecase-prioritizer`는 기업의 AX/DX 담당자, 컨설턴트, 경영기획 담당자가 업무 프로세스 목록과 pain point를 입력해 AI 적용 후보 과제를 빠르게 도출하고 우선순위를 정할 때 사용하는 Codex 플러그인입니다. 반복업무, 수작업, 병목, 데이터 활용 가능성, 리스크, ROI 가설을 기준으로 Quick Win과 PoC 후보를 선별하는 데 사용합니다.

## 2. 왜 이 문제를 선택했나요?

많은 기업은 생성형 AI 도입 필요성을 인식하지만 실제 업무 중 어디부터 시작해야 할지 판단하기 어렵습니다. 삼일PwC AX Node는 기업의 데이터 기반 의사결정, AI 적용 조직구조, 디지털 환경, 비즈니스 프로세스 구축을 지원한다고 공개적으로 설명합니다. 따라서 “업무 pain point를 AX use case로 전환하고 우선순위를 정하는 문제”는 삼일PwC의 산업적 맥락과 직접적으로 연결됩니다.

## 3. 플러그인은 어떻게 작동하나요?

사용자는 업무 프로세스 목록, pain point, 데이터 보유 현황, 시스템 제약, 담당 조직 정보를 입력합니다. 플러그인은 각 업무를 반복성, 수작업 비중, 데이터 준비도, 비즈니스 영향, 구현 난이도, 보안/규제 리스크, 조직 수용성 기준으로 평가합니다. 이후 AX use case 후보, 우선순위 매트릭스, Quick Win/Strategic Bet/Risky Bet 분류, 4주 PoC 계획, 리스크/거버넌스 체크리스트, 임원 보고용 1페이지 요약을 생성합니다.

## 4. AI를 어떻게 활용했나요?

AI는 공개자료 기반 문제정의, AX 우선순위 평가기준 설계, 컨설팅 산출물 포맷 구성, `SKILL.md` 작성, 샘플 업무 목록 생성, 검증 체크리스트 설계에 활용했습니다. 단, 삼일PwC 내부 방법론을 아는 것처럼 작성하지 않고 공개자료에서 확인 가능한 AX Node의 일반적 흐름에 맞춰 범용 프레임워크로 구성했습니다.

## 5. 어떻게 검증했나요?

가상의 중견기업 업무 목록 12개를 샘플 입력으로 넣고, 플러그인이 Quick Win 후보와 PoC 계획을 일관된 기준으로 도출하는지 확인합니다. 검증 기준은 ① 평가 기준의 명확성 ② 우선순위 결과의 설명 가능성 ③ 리스크/거버넌스 누락 여부 ④ PoC 계획의 실행 가능성 ⑤ README·SKILL.md·로그의 정합성입니다.
