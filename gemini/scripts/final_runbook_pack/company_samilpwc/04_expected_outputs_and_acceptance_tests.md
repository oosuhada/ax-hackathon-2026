# 삼일PwC — 예상 출력 및 검증 기준

## 샘플 입력

```text
중견 제조/유통 기업입니다.
업무 pain point:
1. 월말 매출 집계가 수작업 엑셀로 진행됨
2. 고객 문의가 여러 채널에 흩어져 CRM 반영이 늦음
3. 재고 실사와 ERP 재고가 자주 불일치함
4. 계약서 검토에 시간이 오래 걸림
5. 경쟁사 가격 모니터링이 수작업임
데이터는 ERP, CRM, 엑셀 파일, 계약서 PDF로 흩어져 있습니다.
4주 안에 PoC 가능한 AX 과제를 찾고 싶습니다.
```

## 기대 출력

- AX use case 후보 목록
- 평가 매트릭스: 반복성, 데이터 준비도, ROI, 난이도, 리스크
- Quick Win 후보: 월말 매출 집계 자동화, 경쟁사 가격 모니터링 등
- Strategic Bet 후보: CRM 통합/재고 정합성 개선 등
- 4주 PoC 계획
- 데이터/보안/거버넌스 체크리스트
- 임원 보고용 요약

## Acceptance Criteria

| 항목 | 통과 기준 |
|---|---|
| 업무 문제 → AX use case | pain point가 실제 과제로 변환됨 |
| 우선순위 논리 | 기준별 점수와 이유가 있음 |
| 과장 방지 | 전체 전사 혁신처럼 과장하지 않고 PoC 단위로 좁힘 |
| 리스크 포함 | 데이터 보안, 권한, 변화관리, 품질 리스크 포함 |
| 컨설팅 산출물성 | 임원 요약/PoC 계획 형태로 재사용 가능 |
