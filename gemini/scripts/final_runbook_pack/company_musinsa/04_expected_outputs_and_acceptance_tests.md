# 무신사 — 예상 출력 및 검증 기준

## 샘플 입력

```text
성수에서 K-패션 쇼핑을 하고 싶은 일본인 관광객 2명입니다.
예산은 1인당 20만원 정도이고, 캐주얼한 옷, 가방, 신발을 보고 싶어요.
시간은 2시간 정도밖에 없습니다. 무신사 관련 매장 위주로 효율적인 코스를 짜주세요.
```

## 기대 출력

- 사용자 취향 태그: `K-fashion`, `casual`, `bag`, `shoes`, `tourist-friendly`, `2-hour route`
- 추천 코스 2~3개
- 각 코스의 이유
- 방문 전 확인사항: 영업시간, 재고, 세금 환급, 혼잡도, 이동시간
- 한계: 실시간 재고/정확한 도보거리/API 미연동

## Acceptance Criteria

| 항목 | 통과 기준 |
|---|---|
| 문제정의 일치 | 외국인 관광객/K-패션/오프라인 탐색 비용 문제를 다룸 |
| 공개자료 기반 | 무신사 뉴스룸 등 공개자료를 evidence_sources에 명시 |
| 과장 방지 | 실시간 재고나 정확한 거리 계산을 단정하지 않음 |
| 실용성 | 실제 방문자가 쓸 수 있는 코스와 체크리스트 제공 |
| Codex skill 적합성 | 자연어 입력 → 구조화된 Markdown 결과물 생성 가능 |
