## 프롬프트 2 — 스코어링 로직 설계 및 구현
```
상품 정보(상품명, 설명, 가격, "자체제작" 표기 여부, 카테고리 평균가, 고객리뷰 텍스트
리스트)를 입력받아서 "택갈이 의심 스코어"를 0~100으로 계산하는 Python 스크립트를
만들어줘.

신호는 4가지야:
1. REVIEW_FLAG (높은 가중치): 리뷰에 "택갈이", "짝퉁", "중국산", "라벨" 같은
   의심 키워드가 있는지
2. PRICE_ANOMALY (중간 가중치): 가격이 카테고리 평균 대비 비정상적으로 낮은지
   (예: 평균의 40% 미만)
3. DESC_GENERIC (중간 가중치): "자체제작"이라고 표기했는데 설명이 소재/공정/
   브랜드 스토리 없이 일반적인 문구로만 채워져 있는지
4. MANUAL_MATCH (높은 가중치): 사용자가 직접 입력하는 "유사상품 발견 여부" 플래그

각 신호에 대한 가중치는 네가 합리적으로 제안하고, 왜 그렇게 정했는지 설명해줘.
파일은 src/skills/tag-swap-detector/score.py 로 만들어줘.
```

## 프롬프트 3 — 리뷰 텍스트 키워드 탐지 고도화
```
방금 만든 REVIEW_FLAG 로직이 단순 키워드 매칭이라 오탐이 있을 수 있어.
예를 들어 "이거 절대 짝퉁 아니에요 정품 맞아요" 같은 리뷰는 오히려 신뢰를
보증하는 리뷰인데 키워드만 보면 의심으로 잘못 분류될 수 있잖아.
이런 부정 표현(반박/보증 맥락)을 구분하는 방법을 제안하고 구현해줘.
```

## 프롬프트 4 — 검토 우선순위 리포트 생성기
```
스코어와 신호별 근거를 입력받아서, MD 리포트를 자동 생성하는 함수를 추가해줘.

구조:
1. 상품 정보 요약
2. 택갈이 의심 스코어 (0~100)
3. 스코어 근거 (어떤 신호가 얼마나 기여했는지)
4. 검토 우선순위 등급 (상/중/하 — 70점 이상 상, 40~69 중, 40 미만 하)
5. MD 담당자가 추가로 확인해야 할 체크리스트
```

## 프롬프트 5 — 테스트
```
아래 3개 케이스로 테스트해줘.

케이스1 (의심 높음): 상품명 "OO 프리미엄 니트", 가격 9,900원(카테고리 평균 45,000원),
자체제작 표기 O, 설명 "따뜻하고 예쁜 니트입니다", 리뷰 3건 중 1건에 "이거 중국
직구랑 똑같이 생겼어요" 포함

케이스2 (의심 낮음): 상품명 "OO 시그니처 재킷", 가격 128,000원(카테고리 평균
120,000원), 자체제작 표기 O, 설명에 원단 소재/제작 공정/디자이너 코멘트 포함,
리뷰에 의심 키워드 없음

케이스3 (애매한 경우): 리뷰에 "짝퉁 아니고 정품 맞아요"라는 문구만 있는 경우
→ 이게 오탐 방지 로직이 제대로 작동하는지 확인용

각각 스코어/등급/리포트를 보여주고 이상한 부분 있으면 먼저 지적해줘.
```
