## 프롬프트 2 — 표준 조서 카테고리 정의 요청
```
일반적인 재무제표 감사에서 다루는 표준 조서 카테고리를 공개된 회계감사기준
(예: 재무상태표, 손익계산서, 현금흐름표, 자본변동표, 주석, 내부통제평가서 등)
기준으로 정리해줘. 실제 특정 회계법인의 비공개 조서 양식이 아니라, 일반적으로
공개된 감사기준서/회계기준 수준에서 알려진 카테고리로만 정리해야 해. 이 리스트를
src/skills/audit-prep-companion/categories.json 으로 저장해줘.
```

## 프롬프트 3 — 파일 표준화 로직 구현
```
조서 파일 목록(파일명, 형식, 최종수정일 메타데이터)을 입력받아서:
1. 방금 만든 categories.json 기준 카테고리로 자동 분류하고
2. 권장 명명규칙({카테고리}_{연도}_{버전}.{확장자})으로 리네이밍 제안을 생성하는
Python 스크립트를 만들어줘. 파일은 standardize.py 로 만들어줘.
```

## 프롬프트 4 — 결측/중복/버전불일치 탐지
```
방금 만든 분류 결과를 가지고:
1. categories.json에는 있는데 입력 파일 목록에 없는 카테고리를 "결측"으로 표시
2. 같은 카테고리+연도에 파일이 여러 개면 "중복"으로 표시하고 최종수정일 기준
   최신 파일을 추천
3. 파일명에 있는 연도와 실제 최종수정일의 연도가 다르면 "버전불일치"로 표시

이 로직을 추가하고, 결과를 요약 리포트(MD)로 출력하는 함수도 만들어줘.
```
