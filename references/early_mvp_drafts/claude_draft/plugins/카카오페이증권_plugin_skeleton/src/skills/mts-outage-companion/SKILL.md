# MTS Outage Companion

## 이 스킬은 무엇을 하나요
카카오페이증권 같은 핀테크 증권사에서 MTS(모바일트레이딩시스템) 전산장애가 발생했을 때,
1) 장애 로그/설명을 받아 유형을 분류하고
2) 유사 과거 사례(공개 보도 기준)와 비교해 재발 패턴을 짚어주고
3) 고객 공지 초안(사과문 + 조치 안내)을 자동 생성하는 스킬입니다.

## 왜 이 문제인가 (근거)
- 국회 정무위 이양수 의원실이 500만 계좌 이상 보유 증권사 12곳에서 제출받은 자료 기준,
  카카오페이증권은 2026년 1~3월 MTS 전산장애 5건으로 조사 대상 중 최다.
- 2022~2025년 누적 37건으로도 최다, 특히 2022년 4건 → 2025년 13건으로 매년 증가 추세.
- 판관비 대비 IT 투자 비중은 업계 최고(36.5%)인데 절대 투자액은 대형사 대비 1/4 수준
  → "투자는 느는데 장애도 느는" 구조적 모순이 존재.
- 출처: CBS노컷뉴스 2026.4.14 보도 (국회 정무위 제출자료 인용)

## 입력/출력 (설계 예시 — 실제 구현 시 조정)
**입력**: 장애 상황 텍스트 설명 (예: "오전 9시 15분부터 20분간 매수 주문이 체결되지 않음")
**출력**:
1. 장애 유형 태그
2. 유사 과거 사례 언급 (공개 자료 기반)
3. 고객 공지 초안 (한국어, 사과+원인+조치+보상 여부 안내 포함)
4. 내부 체크리스트 (재발방지용)
