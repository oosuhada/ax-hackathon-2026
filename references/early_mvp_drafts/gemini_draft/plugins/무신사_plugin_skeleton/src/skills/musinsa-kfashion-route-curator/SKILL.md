# Purpose
방한 외국인 관광객과 2030 세대가 무신사 스탠다드 및 편집숍 등 다양한 오프라인 매장이 늘어나는 환경에서, 본인의 취향과 이동 동선에 맞는 최적의 매장 방문 코스를 쉽게 짤 수 있도록 돕습니다. 이를 통해 고객 탐색 비용을 줄이고 오프라인 구매 전환율을 높입니다.

# When to use this skill
- 고객이 선호하는 브랜드나 스타일(예: 스트릿, 미니멀, 고프코어 등)을 바탕으로 방문할 무신사 오프라인 매장을 추천받고자 할 때
- 한정된 시간과 특정 지역(예: 성수동, 홍대, 강남 등) 내에서 가장 효율적인 쇼핑 동선을 계획할 때

# Required inputs
- `customer_preference`: 선호하는 패션 스타일 및 관심 브랜드 목록
- `location_constraints`: 방문 예정 지역 및 허용 가능한 이동 시간/거리

# Workflow
1. **요구사항 분석**: 사용자의 취향 키워드와 제약 조건을 파악합니다.
2. **매장 매칭**: 해당 취향과 브랜드를 취급하는 무신사 오프라인 매장(무신사 스탠다드, 엠프티, 오프라인 플래그십 스토어 등)을 필터링합니다.
3. **동선 최적화**: 선택된 매장들의 지리적 위치를 고려하여 최적의 방문 순서와 예상 소요 시간을 계산합니다.
4. **코스 제안 리포트 생성**: 추천 매장 정보, 매장별 추천 이유, 이동 동선을 포함한 맞춤형 쇼핑 코스를 생성합니다.

# Output format
- 제안하는 매장 리스트 (이름, 위치, 추천 이유)
- 시간 순서대로 정리된 최적의 방문 동선 가이드
- 각 매장 주변의 연계 방문 추천 장소 (선택적)

# Validation checklist
- [ ] 제안된 매장이 사용자의 취향(스타일/브랜드)과 일치하는가?
- [ ] 제안된 동선이 지리적으로 타당하며 시간 제약을 준수하는가?
- [ ] 실존하는 무신사 오프라인 매장 정보를 기반으로 작성되었는가?

# Guardrails
- **DO NOT** make up stores. 존재하지 않는 매장이나 브랜드를 지어내지 마십시오. 정보가 확실하지 않은 경우 사용자에게 확인을 요청하십시오.
- 특정 브랜드에 대한 과도한 편향을 피하고, 사용자의 입력 취향에 최대한 객관적으로 부합하는 매장을 추천해야 합니다.

# Example
사용자가 "성수동 근처에서 3시간 동안 고프코어 및 스트릿 브랜드를 보고 싶다"고 입력하면, Codex는 성수동 일대의 관련 무신사 계열 오프라인 매장(예: 무신사 엠프티 성수 등)을 나열하고, 동선(A 매장 -> B 매장)과 소요 시간을 포함한 친절한 가이드를 제공합니다.
