# 무신사: musinsa-kfashion-route-curator 플러그인

이 플러그인은 방한 외국인 관광객과 2030 세대를 대상으로, 무신사의 다양한 오프라인 매장을 취향과 제약(시간/장소)에 맞게 큐레이션하여 최적의 K-패션 쇼핑 코스를 제안하는 Codex 플러그인입니다.

## 1. 플러그인 작동 방식
사용자가 선호하는 패션 스타일과 방문 예정 지역 정보를 제공하면, Codex가 무신사의 오프라인 매장 데이터를 기반으로 맞춤형 매장을 선정하고 최적의 지리적 동선을 계산하여 리포트 형태로 제공합니다.

## 2. 사용 방법
1. Codex 환경에 본 플러그인을 로드합니다 (`src/.codex-plugin/plugin.json`).
2. `musinsa-kfashion-route-curator` 스킬을 호출하고 `customer_preference`와 `location_constraints` 파라미터를 입력합니다.
3. 생성된 맞춤형 무신사 오프라인 쇼핑 코스를 확인합니다.

## 3. 검증 환경
제안된 매장이 사용자의 취향과 부합하는지, 존재하지 않는 허구의 매장을 추천하지 않는지(Hallucination 방지), 그리고 이동 동선이 현실적인지 중점적으로 검증합니다.
