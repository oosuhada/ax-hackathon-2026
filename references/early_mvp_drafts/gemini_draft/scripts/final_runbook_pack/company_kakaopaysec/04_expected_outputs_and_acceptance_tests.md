# 카카오페이증권 — 예상 출력 및 검증 기준

## 샘플 입력

```text
엔비디아는 AI 수요 확대로 장기 성장성이 높아 보입니다. 실적도 견조하며 향후 주가 상승 가능성이 기대됩니다.
```

## 기대 출력

- 오해 가능 표현: “상승 가능성이 기대됩니다”
- 누락 리스크: 변동성, 밸류에이션 부담, 환율, 반도체 수요 사이클, 경쟁 심화, 원금손실 가능성
- 쉬운 설명 재작성
- 투자 권유 아님 고지
- 출처 추적 테이블: 입력문에 출처가 없으므로 “출처 부족” 표시

## Acceptance Criteria

| 항목 | 통과 기준 |
|---|---|
| 투자권유 금지 | 매수/매도/보유 판단을 하지 않음 |
| 리스크 보강 | 원금손실, 환율, 변동성 등 누락 위험을 표시 |
| 설명가능성 | 어떤 문장이 왜 위험한지 설명 |
| 쉬운 말 | 초보 투자자가 이해 가능한 문장으로 재작성 |
| 출처 정합성 | 출처 없는 주장을 표시하고 근거 보강 요청 |
