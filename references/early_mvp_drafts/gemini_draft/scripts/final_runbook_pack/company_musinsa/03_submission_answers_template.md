# 무신사 — 5문항 답변 초안

## 1. 무엇을, 누가, 어떤 상황에서 쓰나요?

`musinsa-kfashion-route-curator`는 외국인 관광객, 2030 고객, K-패션 쇼핑 초심자가 성수·홍대·명동 등 주요 상권에서 자신의 취향과 시간 제약에 맞는 무신사 오프라인 매장 방문 코스를 구성할 때 사용하는 Codex 플러그인입니다. 사용자가 관심 카테고리, 선호 스타일, 예산, 체류 시간, 동행자 정보를 입력하면 Codex가 취향 태그를 추출하고 방문 코스와 체크리스트를 생성합니다.

## 2. 왜 이 문제를 선택했나요?

무신사는 온라인 패션 플랫폼을 넘어 오프라인 매장과 글로벌 관광객 접점을 확대하고 있습니다. 공개 보도자료에 따르면 무신사 오프라인 매장은 외국인 관광객의 K-패션 쇼핑 코스로 주목받고 있으며, 무신사는 대규모 리뷰 데이터를 AI로 요약하는 서비스도 운영합니다. 하지만 고객 입장에서는 여러 매장과 브랜드 정보를 자신의 취향·동선·시간 제약에 맞게 재구성해야 하는 탐색 비용이 남아 있습니다. 이 문제를 Codex 플러그인으로 줄이고자 했습니다.

## 3. 플러그인은 어떻게 작동하나요?

사용자는 상권, 시간, 예산, 관심 카테고리, 선호 스타일을 자연어로 입력합니다. 플러그인은 이를 취향 태그와 제약조건으로 변환하고, 공개자료 기반 상권/매장 정보를 바탕으로 추천 코스 후보를 생성합니다. 이후 각 코스별 적합 이유, 방문 전 확인사항, 매장별 체크포인트, 한계사항을 Markdown 형식으로 출력합니다. 지도 API처럼 정확한 거리 계산을 단정하지 않고 상권 단위의 탐색 가이드로 동작합니다.

## 4. AI를 어떻게 활용했나요?

AI는 문제정의 정교화, 공개자료 근거 정리, 사용자 입력에서 취향·제약조건을 추출하는 워크플로우 설계, `SKILL.md` 작성, 샘플 입력/출력 생성, 검증 체크리스트 작성에 활용했습니다. 최종 판단은 공개자료로 확인 가능한 내용과 해커톤 요구사항에 맞춰 사용자가 검토했습니다.

## 5. 어떻게 검증했나요?

샘플 입력으로 “성수에서 K-패션 쇼핑을 원하는 외국인 관광객, 예산 20만원, 2시간, 캐주얼/가방/신발 관심”이라는 상황을 넣고, 플러그인이 취향 태그, 추천 코스, 각 코스의 이유, 방문 전 확인 체크리스트, 근거와 한계를 일관된 형식으로 출력하는지 확인합니다. 또한 README, SKILL.md, evidence_sources.md, 로그의 문제정의가 서로 일치하는지 점검합니다.
